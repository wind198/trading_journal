# Visual review
Capture before/after desktop (1440x900, 1280x800), tablet (768x1024), mobile (390x844 and 320px width). Use identical seeded or authorized test data and viewport for comparisons; avoid exposing personal records in screenshots. Inspect chart clipping, toolbar overflow, contrast, hierarchy, labels, focus, and touch interactions. Test workspace navigation, fullscreen, calculator, drawing creation/edit/persistence and existing overlays. Record build/test results, screenshots and remaining defects. Do not claim browser validation when not executed.

Verify 2/4-pane visibility at 320×568, 390×844 and 844×390; measure chrome height, pane dimensions and reachability of menus. Test fullscreen exit, expanded drawing toolbar scroll, and pinned notes not obscuring mobile charts by default.
