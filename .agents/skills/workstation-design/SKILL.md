# Workstation design
Reserve the largest region for charts. Use thin separators, restrained accent colors, 4/8/12/16/24 spacing, 13–14px controls, consistent Lucide icons and tabular financial numbers. Separate application navigation from workspace controls. Prefer one inspector with contextual tabs and grouped drawing tools over repeated buttons. On narrow displays preserve simultaneous two/four-chart analysis by default. Use portrait stacks and landscape grids, one compact toolbar, overlay pane labels, and single-chart expansion on demand. Never force single-chart navigation. Preserve the H4/H1/M15/M3 workflow. Read docs/ui-design-system.md for scope and token rules.
