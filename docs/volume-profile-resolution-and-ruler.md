# Configurable volume profile and bar ruler
Inspector Indicators: independent M15/M3 lookback (1–1000, default 96) and resolution (20/30/40, default 30), stored in existing local overlay settings. Price grid spans selected candles' low/high, minimum width 0.00001, origin at low, last bin inclusive of upper bound. Out-of-range ticks clamp to edge bins to retain total counts. Empty price bins are omitted by SQL; selected count is maximum grid resolution, not guaranteed visible nonempty bars. Existing tick-count volume and 70% VA remain. New RPC migration 019 required before frontend deploy; legacy endpoint retains default behavior. Query keys include grid, renderer uses returned frame bin size, no stale profile when settings change. Ruler retains price difference/pips/percentage and adds horizontal bracket and absolute count of chart bar slots (including future whitespace; not wall-clock time). Existing mouse/touch gesture preserved. Tests/build/database/browser not executed.
