# Workspace screenshot
Camera action captures the visible workspace grid (1, 2, or 4 panes), retaining current DOM sizes and arrangement, current chart viewport and all rendered chart primitives via Lightweight Charts takeScreenshot(true,false). Chart canvas includes axes if enabled; timeframe and bias labels are painted separately. Crosshair, application chrome, floating tools, inspector and action buttons are excluded intentionally. Loading/empty/error panes show their actual status; uninitialized chart hosts produce a retryable error. PNG export uses device pixel ratio capped at 2 and 8192px max edge. Native Save As is invoked directly in the click path on supported secure-context browsers; cancellation is silent; otherwise regular PNG download (browser controls destination). No uploads, dependencies or screen-recording permissions. Verify two/four/expanded layouts, portrait/landscape, unequal pane sizes, drawing/indicator visibility, fullscreen, cancellation and browser fallback. Run pnpm test:workspace and pnpm build.

## Touch follow-up
Pane chart content is isolated below header controls; expand/collapse has a non-scrolling hit target (44px on coarse pointers) and no pointer-down pane activation before the click. Layout popover explicitly dismisses on capture-phase outside pointerdown, including chart surfaces that prevent synthesized clicks; inside controls remain interactive and Escape retains Radix behavior. Browser harness includes one-tap expand/collapse and outside dismissal checks. Physical tablet verification outstanding.
