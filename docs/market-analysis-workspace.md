# Phase 3 — independent workspace

Authenticated /market-analysis route; explicit POST scan, fixed EURUSD, max 400 completed bars per timeframe. One UTC as-of cutoff; use preaggregated provider open timestamps and convert to closes. Return snapshot, report and indicator series together. No auto polling, database writes, order access or LLM. Cancellation stops client waiting; server work is not guaranteed to cancel. Prior snapshot remains visibly dated during refresh/error. No persistence or cross-instance rate limiting yet.

Chart views: overview (ADX/ER), trend (Tenkan/Kijun and aligned cloud span lines), range (Bollinger), momentum (signed force), transition (bandwidth/ATR). Both timeframes always visible with responsive stack/grid. Charts label UTC close timestamps; use theme tokens and ResizeObserver cleanup. Evidence inspector shows tool status, numerical features, lookback, provenance and limitations. No fabricated risk report; no AI integration yet. Volume Profile acquisition, cloud shading and historical replay deferred. All thresholds experimental.

Known verification limits: Next installed docs and Lightweight Charts installed typings unavailable in connector-only environment; existing v5 usage and repo skills used. Build, fixtures, browser screenshots and live Supabase smoke test not executed. Run pnpm test:market-analysis and pnpm build; verify desktop/mobile layout, navigation, cancellation, stale/empty/error cases and existing dashboard regression. The in-memory response is a captured view, not a database-transaction snapshot; upstream historical corrections may occur. Next phase: SDK and risk review, authentication/rate-limit hardening and persistence.
