# Named market opening guides
Replace eight anonymous clock slots with four stable market identities. Defaults in chart timezone (Asia/Ho_Chi_Minh unless configured): Sydney 04:00 violet, Tokyo 07:00 red, London 14:00 blue, New York 19:30 green. These are editable trading conventions, not authoritative exchange opening times. Manual DST changes apply to all four days in existing today−2…today+1 rendering window; no historical DST calculation, no exchange holiday/weekend filter, no changes to non-trade warning rules. Existing session grid attachment scope unchanged. Inspector → Indicators → Market openings → Edit opening times; toggle each market separately; save/cancel/reset. Existing overlay localStorage retains named visibility and times; migrate legacy Tokyo/London/New York matching slots, Sydney defaults on. Chart updates via primitive inputs, no chart recreation. Colors and names painted into chart canvas, thus included in screenshots. Coincident session lines retain separate IDs but can overlap visually. No dependencies or database changes. Run pnpm test:ui and pnpm build; verify native time inputs, persistence, colors, chart updates and mobile dialog.
