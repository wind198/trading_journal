# Market opening persistence
Apply migrations/017_market_open_time.sql before deploying. Per-user four market rows, composite key (user_id,market), validated hours/minutes and RLS. Read on workspace mount; missing rows use existing defaults; first successful save upserts all four rows. Changes apply after database acknowledgement; save failure retains last confirmed configuration. Both visibility and time live in Supabase, other chart preferences remain in localStorage. Legacy browser market settings are ignored, not automatically imported (avoid assigning shared-browser data to the wrong account); re-enter custom times once. Chart timezone and colors remain code-defined. Cross-device settings load on workspace reload; no realtime subscription. Verify RLS with two accounts, save failure, reload on another device and fresh account defaults. Migration not applied and build/tests not executed by this change.
