# Analysis session cache
The authenticated app layout owns an in-memory AnalysisSessionProvider. It retains the frozen market snapshot, committed hypothesis, completed passed/failed reviews, preview, analytical profiles, view, pane expansion and visibility across Workspace/Analysis client navigation. Returning to Analysis skips auto-scan when the snapshot exists. Dialog, draft input and workers remain route-local; unfinished scans/searches abort on unmount. No browser storage, database persistence, or background evaluation. Hard reload or leaving authenticated layout resets the cache. Changing the historical cutoff (including switching to Latest) replaces the snapshot only on successful acquisition. Same cutoff is a no-op. Refresh is disabled while completed setups exist to avoid accidental invalidation. Changing entry/direction input is provisional; only a different submitted entry or direction clears old options. Same normalized price/direction reopens cached review. Clear input does not clear committed setups. Chart geometry is still derived from cached review, not persisted pixels. Actual chart zoom is not retained. Existing live VW histogram cache remains chart-local and independent. Browser/build tests not run; installed Next docs unavailable.
