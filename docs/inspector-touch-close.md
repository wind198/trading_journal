# Inspector close reliability
Source review: the close button used icon-sm without a coarse-pointer target, and chart descendants and inspector content did not have explicit independent stacking contexts. These are possible interaction risks; the source does not establish the actual tablet failure. Isolate the chart grid beneath the inspector, keep the header above scrollable content, give coarse pointer devices a 44px close target and 48px header, and keep hidden inspector inert while preserving mounted note state. Use native button click (not pointerdown), retain Escape/focus restoration, and idempotent close. Regression harness checks real hit-test target, touch target dimensions and one tap in expanded, fullscreen and focus layouts. Build/browser and physical tablet verification outstanding.
