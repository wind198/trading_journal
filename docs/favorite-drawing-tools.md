# Favorite drawing tools
Open drawing dropdown → Show favorites toolbar or Customize favorites. Select favorite tools via checkboxes. Floating strip appears at bottom center of chart workspace, without resizing panes, including fullscreen. Cursor/cancel, settings and hide remain fixed; favorite tools scroll horizontally on narrow screens. Favorites and visibility persist per browser in trading-workspace.favorite-tools:v1. Hidden by default; temporary suppression while inspector is open does not alter saved preference. All controls share existing active pane drawing state; no new geometry or runtime dependency. Verify reload, show/hide, narrow screens, fullscreen, active pane change, customization, and toolbar overlap with touch drawing.
