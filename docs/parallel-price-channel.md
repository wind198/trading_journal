# Parallel price channel
Three anchors A/B define baseline, C defines signed price offset from baseline at C time. Boundaries use A/B time span and a dashed midpoint; positive/negative offset and reversed time supported. Desktop click three points; touch uses existing seed/drag/tap confirmation. Select boundary or midpoint then drag anchors or body. Uses chart primitive registry, shared three-point create behavior, existing multi-point edit persistence. Supabase kind TEXT and points JSONB already support this object; no migration required. Available in drawing menu and favorites customization. This PR is stacked on PR #8. Run pnpm test:ui and pnpm build, verify touch creation, edit, cancellation, reload, deletion and favorites on phone and desktop.
