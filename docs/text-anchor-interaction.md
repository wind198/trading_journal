# Text anchor interaction
Root causes in existing code: text bypasses shared creation store as a one-shot tool; no preview/relative touch positioning; label press moves anchor directly to pointer and waits to capture until threshold; bitmap rendering uses unscaled font while hit boxes use CSS pixel dimensions; label modal waits for database insert and leaves empty object when cancelled.
New flow: mouse hover preview then click; touch seed at viewport center, drag relative to anchor, tap confirm. Both open text editor immediately and save only after nonempty confirmation. Cancel leaves no record. Drag label/anchor with initial grab offset preserved through existing relative pointer session; lock chart during pending press; tap selects without movement, double-click/tap edits label as before. Media-coordinate rendering uses 14px label and matching 18px line height; existing persisted text remains compatible. No schema/dependency change.
