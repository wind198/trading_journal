# Iterative structural search

Submit starts a dedicated module Web Worker with the frozen workspace snapshot and confirmed hypothesis. No fetches, order execution, or automatic trade evaluation. Five stages: baseline, 2x, 4x, alternative anchors, buffer sensitivity. Candidate pairs remain within one timeframe and scale. Range boundary pairs never mix inner/outer or zone/boundary anchors. Larger-scale range pairs require usable choppy profile and entry inside range. Active zone pairs and intact confirmed extrema (loss side) extend discovery; pivot stops opt-in only. Buffers 0.15/0.25/0.5 ATR with original target buffer. Existing evaluator and hard policy unchanged; every retained candidate receives complete review, including failures. Target 5 combined, geometry diversity >=5 points on either endpoint, max 100 full evaluations, cooperative 2s budget checked between stages and candidates (not a hard wall-clock cap; entry review/stage enumeration may overrun). Max 8 anchors per side per assessment. Stop reason and stage counts reported; attempted raw combinations can include duplicates across stages. Progress in review sheet; cancellation terminates worker and discards unfinished results; new snapshot/entry/direction cancels old worker; stale worker messages ignored. No fallback blocking main thread. Initial five distinct candidates are not optimized or guaranteed to include a passing setup; wider range feasibility still uses existing baseline evaluator gates, so broader geometry can be rejected by baseline structural infeasibility. Thresholds experimental. Two fixtures appended; tests, worker bundling, build and browser not executed. Installed Next docs unavailable. No dependencies/migrations.
