# Drawing coordinate integrity
Both rectangles and trendlines use shared chartXAtTime/timeAtChartX. Source-confirmed risks: mismatched logical indices when chart series contain extra slots; fallback logical projection can return an incorrect coordinate; negative logical inverse clamped both timestamps to first bar; coordinate bars were published before series synchronization. Fix paired pixel/timestamp interpolation, reject unresolved or nonfinite mappings, publish timeline after series changes. Missing coordinates suppress rendering until the timeline is available rather than snapping anchors to zero. Existing persisted timestamps are untouched; already corrupted records are not automatically repaired. M3-specific production reproduction and browser validation outstanding. This change extends PR18 because both fixes modify the same coordinate pipeline.
