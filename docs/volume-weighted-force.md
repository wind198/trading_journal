# M3 volume-weighted force
M3 Momentum view replaces signed force with an unsigned 0–100 histogram, green/red direction. M15 and risk evaluator unchanged. Existing service-role RPC volume_profile_time_tick_counts (migration 011) supplies valid priced tick counts over half-open UTC windows, not raw tick downloads or actual traded volume. Initial scan returns optional display-only volumeBars; frozen snapshot remains unchanged. Every minute while live Momentum is mounted and visible, fetch recent rollup candles and corresponding counts; merge into in-memory cache, recompute affected causal windows, use histogram update (historicalUpdate for corrections; full setData only for missing historical insertion or cache trimming). History mode never polls. Current partial candle (if supplied by existing rollup) is provisional; no extrapolation of partial tick counts. Volume P95 previous 100 complete observed bars; null if current/prior counts missing, no synthetic zero. Raw force uses existing config and causal baseline. Tooltip shows raw force, tick count, relative volume and weighted score. Fixed autoscale 0–100; thresholds experimental. Initial volume acquisition failure does not block trade scan. Recent two-bucket correction window, no older correction polling; catch-up limited to 800 bars. Cache lifetime is mounted chart/view; switching view rebuilds from snapshot. Existing rollup freshness determines whether active candle available. No migration or dependency required if migration 011 deployed. Tests added, build/browser/RPC integration unverified; installed Next docs unavailable.
