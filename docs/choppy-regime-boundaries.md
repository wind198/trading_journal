# Choppy fallback and conditional boundary evaluation

Fresh usable snapshots with at least 51 candles, positive ATR and nonzero historical range classify as uptrend/downtrend only when directional criteria agree; otherwise choppy. Unknown is reserved for unavailable data (including cadence gaps). Legacy ranging/transition types retained for compatibility; classifier no longer emits them. Expansion and breakout are secondary states. Choppy uses the existing range strategy with established or provisional historical boundaries; repeated tests and ATR width establish confidence, not future containment. Observed boundaries exclude the current bar. Entry outside boundaries has no rotation pair. Conditional provisional pairs use existing buffers and hard minimum SL/TP/RR; no invented target. Range-breakout uncertainty is a warning rather than automatic rejection; actual outside-boundary entries cannot generate boundary pairs on that timeframe. Confirmed range infeasibility still blocks as before. Evidence details and option source labels show confidence. No automatic trade evaluation changes or order execution.

Limitations: outer range only, existing active-zone obstacle checks remain; nested/inner boundary pairing, compression subtype, boundary penetration and calibration deferred. Cadence gaps conservatively block the entire scan timeframe; future work distinguish closures from feed gaps. Trend classification requires history sufficient for boundary detection. Tests added but not run; build not verified. No dependencies or migrations.
