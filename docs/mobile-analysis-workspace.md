# Mobile-first analysis workspace

The analysis route now fills its existing shell viewport. Default price-only view, M15/M3 simultaneous charts in portrait stack or landscape/desktop grid, individual expand/restore. Compact header, indicator strip, snapshot status and bottom action bar. Existing app shell/navigation untouched. Entry and direction only; no manual SL/TP fields in this route. Chart pick is armed, stages a snapped draft on either chart, then requires explicit confirmation. Draft can be repositioned or cancelled; numeric entry stages the same draft. Escape cancels. A confirmed new entry, changed direction or refreshed snapshot clears previous SL/TP preview. No automatic order placement.

Review and evidence use existing Radix dialog styled as bottom sheet on phones and centered modal on desktop. Review shows global entry warnings and structural alternatives; option preview applies both prices atomically if hypothesis ID/revision/snapshot match, then closes. Focus restored to opener. Detailed numerical assessment collapsible. Reference lines off by default; price-only chart avoids squeezing candles into indicator panes.
